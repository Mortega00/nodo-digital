# Assets de MOVIA Ortopedia (demo)

La demo funciona con fallbacks CSS mientras estas imágenes no existan. Al adaptar para un cliente real, reemplazar por imágenes propias, optimizadas y con licencia adecuada:

- `hero-ortopedia.webp`
- `silla-ruedas.webp`
- `cama-ortopedica.webp`
- `andador.webp`
- `bota-walker.webp`
- `muletas.webp`
- `colchon-antiescaras.webp`

No usar fotos de stock sin validar licencias ni representar equipamiento que el negocio no ofrece.
