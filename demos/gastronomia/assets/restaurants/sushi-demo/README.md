# Assets locales de `sushi-demo`

Este directorio contiene exclusivamente recursos locales de la demo. No hay imágenes remotas ni servicios externos en tiempo de ejecución.

## QR

QARTA admite un QR local mediante `restaurant.qr.asset` en `qarta-data.js`. Cuando se reciba el QR definitivo, guardarlo, por ejemplo, en `qr/menu-qr.svg` y colocar esa ruta en la configuración. Mientras tanto, la interfaz muestra el enlace público real de esta demo y no simula un código QR.
